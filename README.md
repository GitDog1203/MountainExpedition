# Mountain Expedition

Mountain Expedition is a mountain climbing game I made for the M5Stack Cardputer ADV.

The game has 3 levels, where you climb through the mountains while managing your supplies and equipment. You have to keep track of your rations and gear as you make your way through the expedition.

## Features

- 3 mountain levels
- Ration management system
- Gear and inventory management
- Mountain climbing gameplay
- Made for the M5Stack Cardputer ADV

## Installation

You can download the precompiled firmware from the [Releases](../../releases) page.

1. Download the merged `.bin` firmware file.
2. Connect your Cardputer ADV to your computer.
3. Flash the firmware onto your device.

## Source Code

The source code is included in this repository. It is split across multiple `.h` and `.cpp` files, along with the main Arduino sketch.
